# Previous experimental engines — reference only

These specialized simulation scripts are preserved for study and regression, but are **not silently fused into the live v0.18 core**. Version 0.12 focused on energy/ecology, 0.13 on individual species and predators, and 0.14 on RSW/Fear Logic and institutions. They used different assumptions and logging conventions. The active executable is `founders_civ/core/engine.py` carried from the integrated v0.17 development branch.

Read `../docs/CANONICAL_SIMULATION_SPEC.md` and `../docs/RELEASE_NOTES.md` for which rules are canonical and which algorithms remain provisional.
